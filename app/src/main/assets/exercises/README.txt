Drop optional exercise images here, named <slug>.jpg / .png / .jpeg / .webp

The slug is the exercise name, lowercased, with non-alphanumeric runs
replaced by hyphens. Examples:

  Jumping Jacks               -> jumping-jacks.jpg
  High Plank Knee-to-Elbow    -> high-plank-knee-to-elbow.jpg
  4-Count Burpees             -> 4-count-burpees.jpg
  Side Plank Oblique Crunch L -> side-plank-oblique-crunch-l.jpg

Any exercise without a file here simply shows the search buttons instead.
